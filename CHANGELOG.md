# Changelog

## 1.0.0 (2026-10-24)

First stable release of API Atlas.

### Catalog

- 5227 records (4117 APIs, 1110 datasets) across 45 of 49 categories.
- 3013 distinct provider identities; 173 records merged from more than one upstream source.
- 90 curated seed entries with verified or partial confidence.
- Three verification tiers: 88 verified, 3825 partial, 1314 imported (counts shift with each refresh).

### Tooling

- Python package `regipy` with CLI: import, build, search, show, export, stats, validate, linkcheck, dedupe, merge, alternatives, flag, flags, categories, set, enrich.
- SQLite FTS5 search index rebuilt with `build`.
- JSON Schema plus semantic validation with `validate`.
- Coverage and reference-question reports generated by `scripts/report.py` and `scripts/answer_checks.py`.

### Automation

- Weekly link check via `.github/workflows/validate.yml`.
- Monthly full refresh via `.github/workflows/refresh.yml` (re-import, enrich, full link check, dedupe, build, validate, report regeneration, tests).

### Deduplication

- First dedupe review completed: 20 candidate pairs, all `shared_website` (distinct products behind one landing page), 0 merges applied. See `reports/dedupe-review.md`.
